# raymondlei.github.io

Personal portfolio and teaching archive for Raymond Lei, built with Jekyll and hosted on GitHub Pages.

## Structure

- `/` — professional overview, expertise, selected work, and education
- `/Projects/` — embedded systems and application project details
- `/ECE422/` — archived Microcontroller System Design course information
- `/blog/` — notes and site updates

Shared page structure lives in `_layouts/`, and the responsive visual system is defined in `styles/screen.css`.
